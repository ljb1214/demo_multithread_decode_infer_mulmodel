# RK3588 多路音视频 AI 推流

## 项目简介

本项目基于瑞芯微 RK3588 平台，实现 **4 路 1080p 视频流实时 AI 分析系统**。整合 FFmpeg 拉流、MPP 硬件编解码、RKNN NPU 推理、RGA 硬件加速及 RTMP 推流，完成从视频输入到 AI 结果输出的全链路处理。

**核心指标**：4 路并发 1080p，端到端帧率 > 50 FPS。

## 技术栈

| 类别    | 技术                |
| ----- | ----------------- |
| 编程语言  | C++               |
| 视频处理  | FFmpeg、MPP（硬件编解码） |
| AI 推理 | RKNN-Toolkit、NPU  |
| 硬件加速  | RGA（图像预处理）        |
| 流媒体协议 | RTSP、RTMP         |
| 系统编程  | 多线程、内存池、线程池       |

## 系统架构

RTSP/MP4 输入
↓
FFmpeg 拉流
↓
MPP 硬件解码（H.264/H.265）
↓
RGA 硬件加速预处理（缩放/格式转换）
↓
RKNN NPU 推理（多模型并行）
↓
DetectionFusionManager（IoU 匹配 + 帧淘汰）
↓
MPP 硬件编码
↓
FFmpeg RTMP 推流
↓
输出（带 OSD 信息

## 核心功能

### 1. 多路视频流处理

- 支持 4 路 RTSP/MP4 视频流实时拉取
- 解决多路流同步、负载均衡与数据对齐问题

### 2. 硬件解码与编码

- 基于 FFmpeg + MPP 实现 H.264/H.265 硬解
- 设计解码回调与共享缓冲区机制，解决多线程帧堆积与线程安全

### 3. NPU 推理加速

- 基于 RKNN-Toolkit 完成多模型量化与部署
- 构建推理线程池实现 NPU 负载均衡

### 4. 硬件图像预处理

- 采用 RGA 硬件加速预处理（缩放、格式转换）
- 失败自动回退 OpenCV，保障链路稳定性

### 5. 多模型结果融合

- 开发 DetectionFusionManager 模块
- 基于 IoU 与加权算法实现多模型检测框匹配对齐
- 结合旧帧淘汰策略与缓冲区管理，解决流水线内存安全

### 6. 推流与稳定性保障

- MPP 硬件编码 + FFmpeg RTMP 推流
- 实现视频流断线重连与异常重置机制
- 叠加 OSD 信息（检测框、置信度等）

- **硬件**：RK3588 开发板

  - RKNN-Toolkit
  - RGA3 库
